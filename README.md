# BlackRack Services

Web corporativa de BlackRack Services: gestión de equipos, destrucción certificada de datos y reciclaje responsable.

Sitio estático de un solo archivo (`index.html`), sin dependencias ni proceso de build. Solo carga la tipografía Geist desde Google Fonts.

## Publicar en GitHub Pages

1. Sube este contenido a la raíz de un repositorio.
2. En el repositorio: **Settings → Pages**.
3. En *Build and deployment*, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. En unos minutos la web estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

### Dominio propio

Crea un archivo `CNAME` en la raíz con tu dominio (por ejemplo `blackrackservices.com`) y configura los DNS según la [documentación de GitHub Pages](https://docs.github.com/pages).

## Contacto

El formulario abre el cliente de correo del usuario con destino `info@blackrackservices.com`. Para envío real desde la web, conéctalo a un servicio de formularios (Formspree, Getform, etc.).
