# BlackRack Services

Web corporativa bilingüe, estática y sin build.

- `/es/` versión principal (español)
- `/en/` versión en inglés
- `/` redirige a `/es/`
- `/img/` imágenes compartidas

Publicar: sube todo a la raíz del repositorio y activa GitHub Pages (Settings → Pages → rama `main`, carpeta `/ (root)`).

El formulario abre el correo del usuario con destino `info@blackrackservices.com`.
